# WoodBlockClassic

A simple block puzzle game built with C# and WPF.

## Features

- Drag & place block shapes
- Clear lines and 3x3 areas
- Score system
- Highscore tracking

## Tech Stack

- C#
- WPF
- MVVM (CommunityToolkit.Mvvm)

## Project Structure

- Core: Game logic
- UI: WPF frontend
- Tests: Unit tests (planned)
